# 🌿 GreenDen – Interior Design Website

GreenDen is a responsive interior design website built using HTML and Tailwind CSS. This project is part of my frontend development learning journey, where I practiced using Tailwind CSS to create a clean, modern, and visually appealing website.

## 🛠️ Technologies Used

* **HTML5** – For structuring the website.
* **Tailwind CSS** – For styling and creating responsive layouts.

## ✨ Features

* 🏡 Modern interior design layout.
* 🎨 Clean and attractive user interface.
* 📱 Responsive design for different screen sizes.
* 🌿 Beautiful presentation of interior design ideas.
* 💻 Styling using Tailwind CSS utility classes.

## 📚 What I Learned

Through this project, I practiced:

* Using Tailwind CSS utility classes.
* Creating layouts with Flexbox and Grid.
* Working with margins, padding, colors, and typography.
* Designing responsive layouts using Tailwind CSS breakpoints.
* Styling images, buttons, and navigation bars.
* Building a modern website using HTML and Tailwind CSS.

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. If you're using the Tailwind CSS Play CDN, open `index.html` in your browser.
4. If you're using a local Tailwind CSS setup, install the dependencies and run the development server using the appropriate command.
